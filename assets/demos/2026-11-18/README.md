# Скринкасты Explorer — 18 ноября 2026

Ролики записаны в VS Code 1.109.0 и 1.144.0 на Linux с Explorer 0.1.23 и компонентами
ESKA 0.32.0. Использованы отдельные профили редактора и искусственная
конфигурация торговли. Все действия выполнены в рабочем интерфейсе. Код 1С
при записи не исполнялся. Предыдущий набор доступен в [архиве](../2026-11/).

## Как обновить записи

1. Создайте новый датированный каталог медиа и собственный демопроект в соседнем
   `eska-playground`. Используйте отдельный профиль VS Code, русскую локаль и
   согласованные версии инструментов.
2. Запишите реальные действия без ускорения и аудиодорожки. Оставьте паузы для
   чтения. Проверьте весь кадр на наличие только демонстрационных данных.
3. Подготовьте MP4 (H.264, `yuv420p`, `faststart`), GIF с отдельной палитрой
   и статичный WebP-постер. Проверьте через `ffprobe`, что MP4 содержит ровно
   одну видеодорожку. Обновите размеры, длительность и SHA-256 в manifest.

Храните медиа в репозитории сайта. README продуктов должны ссылаться на
публичные URL, а дистрибутивы ESKA и VSIX не включают эти файлы.
