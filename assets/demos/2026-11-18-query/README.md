# Сохранение запроса в Explorer — 18 ноября 2026 года

Скринкаст записан в VS Code 1.144.0 на Linux с локальными сборками
Explorer 0.1.23 и `eska-project` 0.32.0.

Откройте строку запроса BSL в отдельной вкладке. Добавьте сортировку и нажмите
**Ctrl+S**, чтобы перенести правку в модуль. Закройте вкладку запроса, чтобы
вернуться к модулю и увидеть изменённую строку.
