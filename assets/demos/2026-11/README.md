# Скринкасты Explorer — ноябрь 2026

Записано 13 ноября 2026 в настоящем окне VS Code 1.144 на Linux,
с установленным VSIX Explorer 0.1.19 и опубликованным `eska-project` 0.30.0.
Использован отдельный профиль редактора и искусственная конфигурация торговли,
без пользовательских исходников и данных. Запись не исполняет код 1С.

Порядок: настройка проводника → дерево метаданных → свойства → формы.
В первом ролике проект уже подключён: заголовок ESKA перетаскивается наверх,
остальные группы сворачиваются, затем раскрывается дерево.

## Форматы и обновление

- GIF: 1248×758, 12 кадров/с, отдельная палитра 256 цветов, бесконечный повтор.
  Подходит для встроенного просмотра в GitHub README.
- MP4: H.264, `yuv420p`, 24 кадра/с, CRF 20, `faststart`, без аудиодорожки.
  Сайт использует `controls`, `playsinline`, `preload="none"`, без autoplay.
- WebP: статичный кадр соответствующего ролика для постера, качество 90.

При новой записи создавайте отдельный датированный каталог. Захватывайте реальный
интерфейс опубликованной версии в отдельном демопроекте внутри соседнего
`eska-playground`. Не добавляйте адреса баз, пользовательские конфигурации,
уведомления или секреты. Не меняйте скорость действий; оставляйте паузы на чтение.
Проверьте весь ролик и наличие ровно одной видеодорожки через `ffprobe`.

Медиа хранятся только в репозитории сайта. В README репозиториев используются
абсолютные URL к GIF; это также работает в карточке расширения. Видео и GIF
не должны добавляться в VSIX, Rust-пакеты или релизные архивы ESKA.
Публикуйте этот каталог до README и проверьте публичные URL после публикации.
