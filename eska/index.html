Полный комплект и выборочная установка

Общая eska запускает установленные компоненты: для eska build нужен eska-build, для eska check — eska-check. Мини-программы работают напрямую без оболочки. Команды ниже устанавливают опубликованный пакет; состав его Assets проверяйте в выбранном выпуске. Установка через Cargo, сборка checkout и настройка Explorer описаны в пошаговой инструкции.

После установки eska --version

Скрипты берут последнюю опубликованную сборку. После установки откройте новый терминал. VSIX и BSL Analyzer устанавливаются отдельно.
