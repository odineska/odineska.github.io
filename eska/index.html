Установить eska

Готовый опубликованный релиз, компоненты через Cargo или сборка checkout — выберите подходящий сценарий.

Текущий проект и публичный релиз

На 22 октября 2026 GitHub latest ESKA — 0.14.3; в нём ещё нет отдельного project ZIP. Для актуальных project/LSP-возможностей установите компоненты 0.15.0 через Cargo или из checkout и соберите Explorer по пошаговой инструкции. Команды ниже устанавливают опубликованный пакет.

$

Linux и macOS

Shell

$ curl --proto '=https' --tlsv1.2 -LsSf \
  https://1c-tooling.github.io/eska/install | sh
›_

Windows

PowerShell

PS> powershell -ExecutionPolicy Bypass -c "irm https://1c-tooling.github.io/eska/install.ps1 | iex"
После установки eska --version

Скрипты берут последнюю опубликованную сборку. После установки откройте новый терминал. VSIX и BSL Analyzer устанавливаются отдельно.
