01 / eska

Инструменты командной строки

Общая команда eska запускает нужный компонент. Каждый инструмент также работает самостоятельно.

CLI · Rust
eska github.com/odineska/eska

eska-project — проекты, приложения, БСП, структура метаданных, свойства, формы и модули.

eska-check — структурная проверка XML и диагностика BSL для CI.

eska-fmt — форматирование BSL и запросов SDBL в редакторе и терминале.

eska-build — сборка и распаковка CF/CFE/EPF/ERF, импорт, патчи и обновление тестовой базы.

eska-vcs — история, семантический diff, ветки задач, коммиты и полки.

eska-debug — запуск с отладкой и подключение к серверу отладки 1С через DAP и HTTP.

Полная ESKA и мини-программы Обработка аудита пользователей БСП

04 / установка

Выберите
способ установки

Короткие команды ставят опубликованный релиз. Полный комплект, выборочная установка мини-программ через Cargo и сборка checkout описаны в руководстве.

$

Linux и macOS

Shell

$ curl --proto '=https' --tlsv1.2 -LsSf \
  https://odineska.github.io/eska/install | sh
›_

Windows

PowerShell

PS> powershell -ExecutionPolicy Bypass -c "irm https://odineska.github.io/eska/install.ps1 | iex"

Проверка после установки: eska --version
