под вашу задачу

Полная ESKA: eska build, eska check, eska status. Мини-программы: eska-build build, eska-check, eska-vcs status. Один проект, два способа запуска; доступные команды и различия описаны в руководстве.

CLI · Rust
eska github.com/odineska/eska
01

Project: метаданные, контекст приложения, свойства и переименование.

02

Check: XML и полный анализ внешним BSL Analyzer для CI.

03

Build: сборка и распаковка .cf, .cfe, .epf, .erf платформой 1С.

04

VCS: задачи, semantic diff, commits и полки; оболочка eska объединяет команды.

02 / explorer

Конфигурация
перед глазами

Объекты и исходники в одном дереве. Свойства, просмотр форм, запросы, BSL и форматирование. Начните с настройки проводника — как на первой записи ниже.

Сначала настройте проводник, затем переходите к дереву, свойствам и формам. Четыре записи без звука; воспроизведение запускается по нажатию.

1. Настроить проводник
2. Найти объект и открыть модуль
3. Посмотреть свойства
4. Открыть форму

Linux · VS Code 1.144 · Explorer 0.1.19 · ESKA 0.30.0. Демо без пользовательских данных. Текущий этап работы с формами — только просмотр (beta); редактирование форм — в планах.

способ установки

Короткие команды ставят опубликованный релиз. Полный комплект, выборочная установка мини-программ через Cargo и сборка checkout описаны в руководстве.

$

Linux и macOS

Shell

$ curl --proto '=https' --tlsv1.2 -LsSf \
  https://odineska.github.io/eska/install | sh
›_

Windows

PowerShell

PS> powershell -ExecutionPolicy Bypass -c "irm https://odineska.github.io/eska/install.ps1 | iex"

Проверка после установки: eska --version
